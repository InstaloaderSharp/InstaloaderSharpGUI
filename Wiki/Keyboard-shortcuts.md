## Shortcuts everywhere

| Keys | Action |
|---|---|
| **Ctrl+Enter**, **F5** | Start the download. While one runs: show the Activity page |
| **Shift+F5** | Stop the download (resume information is saved) |
| **Ctrl+L** | Go to the target box on the Download page |
| **Ctrl+F** | Go to the search box on the Look up page |
| **Ctrl+1** | Download page |
| **Ctrl+2** | Activity page |
| **Ctrl+3** | Look up page |
| **Ctrl+4** | Account page |
| **Ctrl+5** | Settings page |

## In the target box and the target list

| Keys | Where | Action |
|---|---|---|
| **Enter** | Target box | Add what you typed or pasted |
| **Delete** | Target list | Remove the selected targets |
| **Ctrl+A** | Target list | Select all targets |
| **Ctrl+C** | Target list | Copy the selected targets, one per line |
| **Ctrl+V** | Target list | Add the targets on the clipboard |
| **Shift+F10** or the menu key | Target list | Open the context menu: Look up profile, Open on Instagram, Copy, Paste targets, Remove |

See [Adding targets](Adding-targets#the-target-list).

## On the Look up page

| Keys | Action |
|---|---|
| **Enter** | Look up the profile or hashtag. When you typed several words, search Instagram instead |

See [Looking up and searching](Looking-up-and-searching).

## Moving around with the keyboard

- **Tab** and **Shift+Tab** move between the controls. The control that has the focus is outlined.
- In the sidebar, **↑** and **↓** change the page.
- In the sign-in method selector on the Account page, **←** and **→** change the method.
- **Space** flips the focused switch and presses the focused button; **Enter** presses the focused button.
- In a list such as the browser list, the arrow keys choose an entry; **Alt+↓** opens it.
- The account chip at the bottom of the sidebar opens the Account page with **Enter** or **Space**.

## In dialogs

| Keys | Action |
|---|---|
| **Enter** | The main answer, shown on the right (for example **OK**, **Sign in**, **Start download**) |
| **Esc** | Cancel |
